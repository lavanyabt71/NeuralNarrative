NEURAL NARRATIVE — AI BLOG
=========================
1. Extract the ZIP without changing the folder structure.
2. Open this folder in VS Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. For GitHub Pages, upload the contents of this folder to the root of a new public GitHub repository.
5. In Settings > Pages, choose Deploy from a branch, branch main, folder /(root), then Save.

This is a static HTML/CSS/JavaScript website. The contact and newsletter forms are demonstrations only; they do not send or store submissions. No npm install or build step is required.
