How do large language models actually work?

A language model doesn't think by looking up a perfect answer. It learns patterns from examples and uses context to predict what comes next.

WORDS → TOKENS → PATTERNS → PREDICTION

First, text becomes tokens

Before processing a prompt, a language model splits text into smaller units called tokens. A token might be a whole word, part of a word, or punctuation. The model works with numerical representations of these tokens rather than human-readable sentences.

Then the model uses context

During training, the model sees many examples and adjusts a large set of internal parameters to become better at predicting the next token. Transformer architectures use attention mechanisms to help relate different parts of the input context.

Prediction happens one step at a time

When you ask a question, the model calculates likely next tokens based on the prompt and its learned patterns. It selects a token, adds it to the context, and repeats. The result can sound fluent, but fluency is not the same as guaranteed factual accuracy.

THE KEY IDEA

LLMs are powerful pattern-learning systems. They can help explain, draft, summarize, and code — but important outputs still need human checking.
